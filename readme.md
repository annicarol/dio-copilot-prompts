## 💬 ROTEIRO DE ENTREVISTAS  

**PERGUNTA 1:** O que é overfitting?  
**COMO RESPONDER:** Explique que é quando o modelo aprende demais os dados de treino e não generaliza bem.  

**PERGUNTA 2:** Qual a diferença entre supervised e unsupervised learning?  
**COMO RESPONDER:** Supervised usa dados rotulados, unsupervised busca padrões sem rótulos.  

**PERGUNTA 3:** O que é uma rede neural convolucional (CNN)?  
**COMO RESPONDER:** É uma arquitetura usada para imagens, que aplica filtros para extrair características.  

**PERGUNTA 4:** Como você escolheria métricas para avaliar um modelo?  
**COMO RESPONDER:** Depende do problema — acurácia para classificação balanceada, F1-score para classes desbalanceadas.

**COMO RESPONDER:** Relate um exemplo prático, mostrando como identificou o problema e resolveu.
